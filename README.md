## Overview
Business experimentation platform for marketing campaign optimization, enabling data-driven decisions on acquisition strategy, bonus optimization, and customer lifetime value analysis.

## Features
- **Campaign Designer** - Optimize sign-up bonus amounts and predict ROI before spending
- **A/B Test Analyzer** - Statistical significance testing with sample size calculator
- **CLV Calculator** - Customer lifetime value modeling by segment
- **Sensitivity Analysis** - Tornado chart + Monte Carlo simulation (10,000 scenarios)

## Business Questions Answered
- What sign-up bonus maximizes ROI for credit card acquisition?
- Is our A/B test result statistically significant?
- How much is each customer worth over their lifetime?
- Which variables have the biggest impact on campaign profitability?

## Tech Stack
Python, Streamlit, Plotly, SciPy, NumPy, Pandas

## Installation
```bash
pip install -r requirements.txt
streamlit run app.py
```
